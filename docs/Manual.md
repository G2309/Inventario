# Manual de Usuario - Sistema Kardex Bioagricsa

Este documento describe el flujo de operación para el personal de bodega y gerencia.

1. Acceso al Sistema

Para ingresar, debe colocar su nombre de usuario y contraseña en la pantalla de inicio. El sistema reconocerá automáticamente su rol.

2. Recepción de Inventario

En el módulo de Recepciones:

    Ingreso: Seleccione la fecha y la cantidad de costales descargados. Al guardar, el sistema le mostrará el nuevo saldo total en bodega.

    Corrección: Si cometió un error en la cantidad, utilice el botón "Borrar cantidad ingresada" para revertir el último movimiento de esa fecha.

3. Gestión de Despachos y Devoluciones

En el módulo de Despachos:

    Salidas: Ingrese el número de guía de Cargo Expreso, el municipio de destino y la cantidad de sacos.

    Verificación CAEX: Antes de procesar una devolución, ingrese la guía y presione "Verificar en CAEX". El sistema consultará el estado real del paquete para confirmar si debe reingresar a bodega.

    Retornos: Una vez verificado el estado, presione "Registrar como Devolución" para que los sacos vuelvan a estar disponibles.

4. Reportes Gerenciales

En el módulo de Reportes:

    Alerta de Inventario: Puede ajustar el control deslizante (slider) para definir cuándo el número de existencias debe ponerse en color rojo.

    Auditoría: Seleccione una fecha en el calendario para ver quién realizó cada movimiento y a qué hora.

    Exportación: Utilice el menú desplegable para elegir entre un reporte del día o del mes completo y presione el botón de exportar para descargar el archivo de Excel.
